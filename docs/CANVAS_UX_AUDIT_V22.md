## Direction

Keep existing Konva interaction engine, schema3, flat groups, Rough.js and saved v1/v2/v3 semantics. Correct interaction/render bridges without document migration. Selection overlay stays transient. Focus mode is CSS fixed/inset (no permissions or native fullscreen state), desktop panel occupies its own left column, mobile panel remains dismissible. Keep shell and other tools unchanged except explicit release metadata and catalog descriptions. One continuous gesture or explicit style action creates one history transaction.

## Implemented corrections and after evidence

UX-01 now intersects paths and rotated shape outlines, including borders; curves use32 path segments and ellipses48. Ink uses stored polyline geometry; stroke thickness is excluded. Shift box adds, Shift click retains standard toggle. Any intersected group member selects the whole flat group; empty group bounding-box gaps do not select. Optional domain strict containment remains covered. Mouse Select drags empty space; explicit Box select B supports touch.

UX-03 synchronizes the native content Layer child indices after Svelte tick, only when entity ID order changes. Selection/camera/drag samples with unchanged order do not rebuild the scene. Shapes/edges/images share that layer. Real overlap pixel changes green [214,245,237,255] → blue [220,236,249,255]; overlap click selects the blue front figure; Undo and reload preserve the observed order. Screens: v22-layer-before/after-front.

UX-05 midpoint grip sits on the actual path. Dragging a straight path creates a quadratic curve with C=2G−(A+B)/2, keeping stored v3 control semantics intact. The same inverse applies to existing curves; elbows retain world-orthogonal horizontal bend. Handles only listen in Select, avoiding interception while drawing another figure. v22-direct-bend.png and real move/reload/PNG assertions cover this.

UX-02 CSS Focus uses the full viewport and a250px left desktop inspector that reduces the stage footprint. Mobile/tablet begin with inspector closed; all actions remain available without hover. No native Fullscreen permission is requested. Gesture/text Escape precedes panel close then Focus exit; focus/overflow/inert cleanup is verified on navigation. v22-focus-* includes both themes and390/768/1440 plus hierarchy levels2/3.

UX-04 one release module separates appV2.2RC, Canvas2.1RC and immutable build SHA. Registry version fields describe introduction history and are intentionally not relabeled. No service worker/runtime version request was introduced. Final preview/SHA verification remains at release gate.

Additional real-review corrections: mixed property values no longer impersonate the first selected style; explicit changes preserve unrelated styles and selection. HEX commits on completed change rather than each valid keystroke. Numeric sketch options now match numeric state (previous blank dropdown). Hachure text uses theme ink because most of the background remains transparent. Single-element labels/dimensions/child-association editors are suppressed for ambiguous multi-selection; explicit outline child actions remain usable for grouped figures.

Remaining P2: physical touch/stylus and assistive-technology review not simulated as completed; no continuous freehand lasso or nested groups. Curves/ellipses use bounded selection sampling; exact CAD intersections are outside scope. Public deployment verification and complete final regression are still pending.
