## Model, compatibility and data protection

Schema3 is justified by optional rotation/seed, flat per-diagram `Group {id, memberIds}`, connector geometry/control/heads and project `Asset` resources. New defaults preserve legacy semantics. DTOs and pure operations have no Konva/Svelte types. The isolated legacy reader preserves v1/v2's existing 8MiB validation budget; V3 allows 16MiB. Frozen fixtures were exported with the unchanged `c3cd929` reader before implementation. Regression compares complete whitelisted legacy DTOs: stable IDs/Unicode/text, shape styles, ink points, child references (including legacy text children), cameras, free/anchored edges and recoverable orphans. Repeated JSON roundtrips remain equal.

Physical IndexedDB stays `devbench.canvas.v2`, version1, store `projects`; no deletion or destructive upgrade. Opening migrates in memory and does not schedule a rewrite. The first real edited save atomically retains the original legacy JSON once. Revision compare-and-swap blocks stale writes/deleted rows, and unknown future schemas are protected even if an external writer fails to increment the revision. Projects can download raw saved and immutable original backups, including unreadable future documents. Import creates a new project ID and preserves internal IDs; invalid input/codec failure never replaces the open document.

Groups are flat: no nesting or repeated membership. Moving, uniform resizing, rotation and layer changes operate as units. Internal connector endpoints remap on duplication; explicitly duplicated external connectors remain attached to their original outside nodes until a transform that detaches an outside anchor deterministically. Deleting nodes removes incident edges and repairs/dissolves groups; child diagrams remain recoverable. Grouping/rotation/movement never edits child contents. Ink bounds use the actual stored points, including old documents whose points exceed their declared box.

Browser storage is origin-scoped: production and branch/immutable previews have separate databases; explicit JSON export/import transfers a project between them. History records one transaction per continuous gesture, bounds past+future to30 snapshots/about20MiB, and budgets immutable asset strings once across snapshots. Draft pointer samples do not serialize whole projects. Autosave is a serial writer after600ms quiet time; quota/error retains dirty memory and rescue/retry. Undo resets on project switch/reload. Abrupt browser/process termination before Saved can still lose the last edit; local storage is not remote backup.

## Renderer, grouping and connections

[Rough.js4.6.6](https://github.com/pshihn/rough), MIT, improves irregular contours and hachure without replacing Konva interaction/hit-testing/PNG. Its installed published ESM artifact is27748 bytes, gzip8931 bytes; these are library-artifact measurements, **not** an isolated application bundle delta. Rough paths use deterministic per-element seeds (legacy ID-derived fallback). The path signature excludes movement, selection and camera. Hachure spacing scales with size (minimum12, span/80), bounding density even at20000x20000. A regression first measured361930 path characters and now enforces less than100000. Geometric transparent hit shapes remain stable independently of sketch paths. Clean/soft/expressive, solid/transparent/hachure and repeatable palettes are available. Pencil retains moderate smoothing and the existing2000-point stroke/100000-point project caps, with one history action per stroke.

Marquee uses inclusive full world-coordinate bounds containment in all four drag directions. Shift XOR toggles from the starting selection; groups are whole units. Stroke/head thickness is excluded; ink uses point bounds and connections use their geometric path. Empty click clears, Escape restores the starting selection without history. Ctrl/Cmd+A, Delete, grouping shortcuts and outline are available without hijacking input fields.

Rotation uses center pivots and local normalized anchors; group resize is uniform to avoid shear. Single resize keeps the opposite rotated corner fixed. Six alignments and horizontal/vertical distribution operate on separate figures/groups. Straight, quadratic curve and world-orthogonal elbow connectors have editable endpoints/control, none/end/both heads, stroke width/color/dash. Elbow bend control changes the horizontal bend; vertical segments follow endpoints. No obstacle routing. Degenerate repeated vertices are skipped when orienting heads; a fully zero-length path has no misleading head.

## Hierarchy and independent duplication

Direct open and the animated zoom action use the same child ID. Breadcrumb, per-level camera, Escape/reduced-motion and recoverable unlinked diagrams remain. The zoom portal is an initial visual transition, not continuous infinite semantic zoom.

Duplicate defaults to an **independent sub-tree**. A memoized source→copy diagram map copies a shared DAG once, creates fresh diagram/element/edge/group IDs, remaps child/internal connector links and preserves text/styles/ink/cameras. Limits and full validation precede the atomic commit/undo step. Immutable raster resources can be shared safely while copied image nodes transform independently. “Duplicate with shared child” is a separate action with a ⇉ indicator and explicit inspector warning. Browser acceptance edits a third-level copied descendant and verifies the original architecture is unchanged, then verifies the linked alternative remains shared.

## Local images and touch

Static local PNG/JPEG/WebP files require explicit selection, matching MIME/signature, bounded chunks/dimensions and canonical base64. Header checks run before bitmap allocation; actual browser decode must match dimensions before import/load is accepted. PNG animation, WebP animation, repeated/inconsistent frame headers, SVG and remote URLs reject. Limits:1MiB/4MP/4096px per image,4MiB source bytes/8MP decoded per project,32 assets maximum within the JSON budget. A4s decoder deadline stops waiting and closes late results.

Assets are embedded in V3 JSON, not external references. Move/resize/rotate/group/layers/history/PNG work on image nodes; duplicates share immutable resources. Deleting the last use removes that particular resource transactionally with undo. Cache is per mounted editor; unchanged resources reuse bitmaps and removal/cancellation/error/unmount closes them. PNG refuses placeholders. Tests cover real PNG/JPEG/WebP decode, a pixel-exact exported PNG, portable import/reload, quota/rescue/retry and a header-valid but undecodable PNG that leaves the open project unchanged.

Mouse/trackpad: wheel pans, Ctrl/Cmd+wheel zooms at pointer, hand/middle/Space pan. Touch: tap/selection, drag, natural pan over empty canvas and midpoint-centered pinch; a second pointer cancels uncommitted creation before pinch. Pointer capture keeps gestures coherent. Scroll outside the canvas remains normal. Stylus uses Pointer Events; pressure is not implemented. CDP emulation is evidence for event handling, not proof on physical devices.

Imports/labels are data, not executable HTML. Project/image errors do not dump input. All27 other entries retain their prior memory-only behavior and regression flows, including OpenAPI external references without fetch and explicit redacted one-use HTTP handoff.
